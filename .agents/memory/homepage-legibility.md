---
name: Homepage legibility treatment
description: Visual rules for keeping the transparent mobile trading homepage readable over the desert artwork.
---

The homepage should preserve the transparent glass aesthetic while prioritizing legibility: blur the mobile artwork itself, use black text with green reserved for positive/healthy states, enlarge micro-labels, strengthen row separation, and apply a subtle dark drop shadow to homepage text. Do not add a white text halo.

**Why:** The detailed desert artwork competes with small dashboard typography when it shows through the cards.

**How to apply:** Preserve these rules when refining the homepage glass, typography, navigation, or mobile background treatment.
