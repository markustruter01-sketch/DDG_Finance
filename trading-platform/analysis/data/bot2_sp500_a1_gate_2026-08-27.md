## Price-panel validation

Alpaca SIP returned historical bars for the consolidated-tape slice
2018-01-01 through 2025-12-31. The configured subscription rejected recent SIP
queries, so the isolated ingestor used Alpaca IEX only for the 2026 slice and
labels those rows separately. This is not a substitute for the membership
gate.

- Symbols attempted: 668
- Symbols with bars: 667
- Empty response: `BCR`
- Stored daily rows: 1,322,877
- Coverage failures: 42 symbols

The failures include large, explainable listing/ticker-history holes such as:

- `BBWI`: missing 902 active sessions before its 2021 listing/ticker history
- `CDAY`: missing 644 sessions before its 2024 listing
- `DAY`: missing 1,533 sessions before its 2024 listing
- `PSKY`: missing 1,909 sessions before its 2025 listing
- `VTRS`: missing 722 sessions before its 2020 listing
- `STI`, `CTRA`, `FLT`, and `LIN`: similar unmodeled historical ticker or
  security-identity boundaries
- `BCR`: no Alpaca price history returned
- 30 additional symbols have isolated missing sessions that require a
  security-master/calendar explanation rather than imputation

Because the public event log treats several current symbols as active from the
2018 analysis start, these are not safe to repair by filling prices or by
substituting the current 245-symbol universe. The result would be
survivorship/temporal bias.

## Follow-up required before testing

Obtain a research-grade point-in-time constituent/security-master source with
audited effective dates and identifier-linked delisted history (for example
CRSP/WRDS, Norgate, or an equivalent licensed source), or provide a public
source that meets the same criteria. Then rerun the A1 validator. No earnings
audit, experiment registration, backtest, or live-module work was started
because the plan requires the membership gate to pass first.
